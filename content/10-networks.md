Your agent has one balance and Solana is its home. Other chains are routes your agent can use when a task needs them.

| Network | What works | Status |
| --- | --- | --- |
| **Solana** | Agent wallet, sends, Orca swaps, agent payments, top ups (devnet). Jupiter quotes read mainnet prices | [[testnet]] |
| **Base** | Agent EVM address, balances, top ups (Base Sepolia) | [[testnet]] |
| **Ethereum** | Agent EVM address, balances, top ups (Sepolia) | [[testnet]] |
| **Arbitrum** | Top ups and balances (Arbitrum Sepolia) | [[testnet]] |
| **Monad** | MON balance, AUSD, top ups (Monad testnet) | [[testnet]] |
| **Hyperliquid** | Perp orders with a trade-only key, HYPE top ups on HyperEVM (testnet) | [[testnet]] |
| **Tempo** | Stablecoin sends, faucet, agent card, top ups (Moderato testnet) | [[testnet]] |
| **Robinhood Chain** | Deposits into your balance | [[soon]] |
| **Zcash** | Deposits into your balance | [[soon]] |

Top ups also accept BNB Chain, Bitcoin, Litecoin, Tron and XRP Ledger test networks. See [top ups](/balance).

> [!NOTE]
> Mainnet for agent wallets is paused. When it opens, each network page in the app will say so, and these docs will be updated.
